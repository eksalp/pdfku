Privasi, keamanan & syarat

Penjelasan jujur tentang apa yang terjadi pada file kamu.

Singkatnya

  • Semua alat memproses file di perangkatmu sendiri. File tidak pernah di-upload ke server mana pun.
  • Kami tidak menyimpan, membaca, atau menyalin file kamu.
  • Tidak perlu daftar, tidak ada login, tidak ada cookie pelacak.
  • Begitu tab ditutup, semua data hilang dari memori perangkatmu.
  • Alat bertanda lokal memproses file di perangkatmu sendiri. File tidak pernah di-upload.
  • Alat bertanda server mengirim file ke server PDFku lewat koneksi terenkripsi. File langsung dihapus begitu hasilnya dikirim.
  • Kami tidak menyimpan, membaca, atau memakai isi file kamu untuk apa pun.
  • Tidak perlu daftar, tidak ada login, tidak ada cookie pelacak.

Bagaimana PDFku bekerja

Kebanyakan situs PDF meng-upload file ke server mereka, memprosesnya di sana, lalu mengirim hasilnya kembali. PDFku tidak begitu.Sebagian besar alat PDFku tidak begitu.

Saat kamu membuka PDFku, browser mengunduh aplikasinya, yaitu kode JavaScript dan mesin pengolah PDF. Setelah itu, untuk alat lokal:

  1. File yang kamu pilih dibaca oleh browser ke memori perangkatmu sendiri.
  2. Gabung, pisah, kompres, dan konversi dikerjakan oleh prosesor perangkatmu.
  3. Hasilnya dibuat di perangkatmu, lalu disimpan ke folder unduhan saat kamu menekan Unduh.

Tidak ada satu langkah pun yang mengirim isi file ke internet. Server kami hanya menyajikan halaman web dan tidak pernah menerima file.

Untuk alat server (Word, Excel, dan PowerPoint ke PDF), software yang dibutuhkan terlalu berat untuk berjalan di browser, jadi:

  1. File dikirim ke server PDFku lewat HTTPS (terenkripsi).
  2. Setiap file diproses di folder sementara yang terpisah dari file orang lain.
  3. Begitu hasilnya selesai dikirim ke kamu, file asli dan hasilnya langsung dihapus dari server. Kalau koneksimu putus di tengah jalan, sisa file dihapus otomatis paling lambat dalam 15 menit.
  4. Tidak ada salinan, cadangan, atau arsip. Nama dan isi file tidak dicatat di log.

Kalau dokumenmu sangat rahasia, pakai alat lokal.

Data yang tidak kami kumpulkan

  • Isi file: tidak disimpan, tidak dilihat siapa pun, dan tidak dipakai untuk melatih AI atau keperluan lain.
  • Data pribadi: kami tidak meminta nama, email, atau nomor HP.
  • Pelacakan: tidak ada cookie, Google Analytics, piksel iklan, atau pelacak lain.
  • Pihak ketiga: semua kode, font, dan mesin pengolah PDF di-host di situs PDFku sendiri. Halaman ini tidak memuat apa pun dari Google, CDN, atau layanan lain.

Seperti semua situs web, penyedia hosting bisa mencatat log akses standar, yaitu alamat IP, waktu kunjungan, jenis browser, dan halaman yang dibuka. Log ini dipakai untuk keamanan dan tidak berisi nama file atau isi dokumen kamu.

Pengaman teknis

  • Content Security Policy (CSP): browser hanya mengizinkan halaman ini terhubung ke situs PDFku sendiri. Kode mana pun yang mencoba mengirim data ke tempat lain akan diblokir oleh browser.
  • Alat lokal tidak mengirim file sama sekali. Satu-satunya yang diunduh dari situs PDFku adalah aplikasinya sendiri, termasuk mesin kompres saat pertama kali dipakai.
  • HTTPS: semua koneksi terenkripsi.
  • Tanpa akses perangkat: PDFku tidak meminta akses kamera, mikrofon, lokasi, atau kontak.

Buktikan sendiri

  1. Mode pesawat: buka PDFku dan pakai alat Kompres sekali supaya mesinnya termuat. Lalu matikan internet atau Wi-Fi, dan proses file seperti biasa. Semua alat lokal tetap berjalan.
  2. Developer Tools: di komputer, tekan F12 lalu buka tab Network. Proses sebuah file dengan alat lokal. Tidak ada data yang dikirim keluar.

Syarat penggunaan

  • PDFku gratis dan disediakan apa adanya, tanpa jaminan bahwa hasilnya selalu sempurna untuk setiap file.
  • Simpan selalu salinan file aslimu. Hasil proses adalah file baru, dan file asli tidak diubah.
  • Gunakan PDFku hanya untuk file yang berhak kamu olah. Tanggung jawab atas isi file ada pada pengguna.
  • Kecepatan dan batas ukuran file bergantung pada memori perangkatmu. File sangat besar paling lancar diproses di komputer.
  • Alat server punya batas ukuran file dan jumlah pemakaian. Hasil konversi Word/Excel/PowerPoint bisa sedikit berbeda dari aslinya, terutama jika dokumen memakai font khusus.
  • PDF yang dikunci dengan kata sandi belum didukung.
  • Kami tidak bertanggung jawab atas kerugian yang timbul dari penggunaan layanan ini.
  • Kebijakan ini bisa diperbarui. Kalau suatu saat kami menambah iklan, analitik, atau mengubah cara file diproses, halaman ini akan diperbarui lebih dulu.
